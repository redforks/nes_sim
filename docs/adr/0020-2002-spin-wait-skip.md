# $2002 spin-wait skip: quiet span on the declaration anchor grid

## Status

Active. Supersedes ADR-0019 (`0019-spin-wait-freeze-contract.md`) per spec #167, implementing the #165 contract as built (tickets #168–#171). ADR-0019 stays as the record of the reverted freeze design; its synthesized-exit contract must not be restored.

Game code waits for vblank by spinning on `$2002`: `BIT $2002 / BPL loop` (or `LDA $2002 / BEQ loop`). Burning those iterations instruction-by-instruction is measurable idle cost (issue #164). The freeze (#132, ADR-0019) tried to skip them and was reverted: SMB frame-hashed diverged at frame 33, Jackal at frame 14, `nmi_sync` drifted in cycles (#155). Its root causes were synthesized CPU action on frozen dots — the wake path called the CPU's edge-latching detectors, and loop-top re-execution shifted later reads off the grid the executing loop would have followed. The revert (#158) restored pre-#132 output (`44addbd`, the permanent reference build) and ADR-0019 was parked.

This ADR records the re-landed skip as built. It differs from the freeze in kind, not just degree: the CPU is *parked* at a clean instruction boundary, the rest of the machine (PPU, APU, DMA, interrupt lines) keeps advancing on the bus-owned dot clock, each skipped poll is replayed through the real published read path on its exact grid dot, and no exit is ever synthesized — real execution always decides the branch, the flag observation, and the interrupt dispatch.

## Considered options

- **Restore the freeze as designed (synthesized VBL exit, frozen-dot detector calls)**: rejected. It diverged frame-visibly (#155); root cause was CPU state mutated on dots where no instruction executes plus off-grid resumes. Kept only as the lesson this ADR's rules encode.
- **Loop-top re-execution as the canonical resume**: rejected as canonical — re-running the fetch-decode prefix after the flag becomes visible puts later reads off the executing loop's grid (ADR-0019's mechanism of failure). It survives solely as the fallback for any wake mismatch.
- **A synthesized poll value or duplicated read semantics on the skip path**: rejected. Each replayed read runs the full published `Mcu::read` path (`Ppu::read_ppureg`), so VBL clear, write-toggle reset, the dot-0 race, and the partial latch refresh are the same code the control executes — nothing is re-implemented to drift.
- **Per-frozen-dot cut and `Cpu::tick` executing-path bookkeeping (freeze-era cost model)**: rejected. The freeze-off control paid ~+12% on SMB; the cost contract here is zero per-instruction work outside a skip, with detection confined to the taken-branch path.
- **Widening scope to device-register polls (`$4015`/`$4016`/`$4017`) and `$2007`**: rejected. Device polls have no single replayable read shape worth this grid, and PPUDATA reads perform non-status device actions (read-buffer refill, v-increment) that a skip would swallow. Scope stays `$2002` (spec #167 story 19).
- **Restoring the freeze-era control hook `set_spin_declaration_disabled_for_test`**: rejected. It was a CPU-internal test seam; the replacement is a machine-level toggle (`NesMachine::set_spin_skip_enabled`), so skip-on and skip-off run in one build through the public API.

## Decision

- **Shape (spec #165 Q1, as built in `nes_core/src/spin_skip.rs`)**: only `BIT abs` ($2C) or `LDA abs` ($AD) reading `$2002`, directly followed by a taken conditional branch (BCC..BVS — structural, via the branch microcode) back to the read. Detection runs only inside the taken-branch path and only for branch offset $FB — the one offset whose target is the 3-byte read directly preceding the 2-byte branch. The match is by opcode and operand bytes peeked side-effect-free at the loop PC (`Mcu::peek`); no emulator state participates. `LDA abs,X`, any other opcode, non-`$2002` operands, forward or non-adjacent branches are refused.
- **Span (tickets #170/#171, `NesMachine::tick_quiet_span`)**: the span runs from the declaration to the first edge dot. The declaring iteration (0) finishes real; parking starts at iteration 1's loop top (anchor+6). The span ends at dot precision at: the replayed poll that observes the VBL flag (or whose end-of-cycle interrupt poll latches) — CPU parked at the branch PC; a `/NMI` or IRQ line event, waking at the next grid top; the first dot a DMA becomes visible; a grid dot consumed by DMA (overshoot) — real execution resumes at the loop top. No synthesized exit: the VBL-set dot and the poll that sees the flag always run real.
- **Grid (spec #165 Q3)**: the counterfactual grid is the PPU dot clock anchored at the loop's *first back-edge* (the declaration's anchor dot). Tops sit at anchor+6+21k, polls at top+9 (BIT/LDA 4 cycles + taken branch 3 cycles = 7 CPU cycles = 21 dots; the read is the poll instruction's 4th cycle). Replayed polls land exactly on the dots the executing loop would have polled — the fix for ADR-0019's loop-top-re-execution drift. A page-crossing back-edge (4 taken cycles) breaks the 21-dot grid: such loops are declared but never armed.
- **Replay semantics**: each replayed `$2002` read drives the real read on its poll dot through the published `Mcu::read` path — VBL clear, write-toggle reset, the dot-0 race (`Ppu::read_status`), and the partial bus-latch refresh (bits 7-5 from status, bits 4-0 kept). The CPU-visible effects go through the one narrow seam `Cpu::apply_spin_poll_result` (BIT sets V/N/Z from the value; LDA loads A; then the branch test decides taken). The replay also owes the standard end-of-cycle interrupt poll (`Cpu::detect_interrupt_at_wake`) — real detector state, live line levels, never detector internals (ADR-0019's lesson). The open-bus decay clock advances by exactly the skipped ticks because `Ppu::tick` keeps running; only `Cpu::tick` is elided. The decay *constant* is untouched (#166 owns that conflict; the contract is constant-agnostic).
- **DMA rules (spec #165 Q8)**: a declaration is refused while `DmaBus::is_busy` (DMC in flight, OAM active, or OAM pending); the refused back-edge simply stays undeclared and a later clean back-edge re-tries. A DMA that becomes visible mid-span ends the span at that very dot — real execution owns the stall; the grid is never stretched by an unmodelled one.
- **Frame-boundary rule (ticket #171)**: the span never parks through the frame-boundary tick (the VBL set at (241,1) — `take_vblank_entered`, scanline 241 dot 1). A poll whose *next* parked iteration would cover the boundary ends the span at that poll with PC at the branch, so the boundary dot and the flag-observing exit poll run real on the control's own cycle grid; a boundary tick landing exactly on the next grid poll keeps parking, because that replay is the control's own read on that exact dot. Symmetrically, a declaration whose first parked iteration would straddle the boundary is declined entirely.
- **Fallback (spec #165 Q9)**: every wake resumes at an instruction boundary — the loop top or the branch PC — from the last completed real iteration; never a partially replayed one. A grid-top wake whose recorded line event was already visible to the control's in-flight branch cycle (NMI sample ≤ top−8, IRQ level ≤ top−6, per the branch-cycle sample/poll lag) runs the standard interrupt poll at the top first so the dispatch lands on the control's dot; a later edge is reproduced by the plain real fetch.
- **Overhead (spec #165 Q7)**: nothing runs per instruction outside a skip. Detection is one integer compare (offset $FB) inside the already-taken branch path; the executing path carries no new state and no per-dot bookkeeping.
- **Arm gate**: the span arms only when the machine-level switch is on, the back-edge does not cross a page, `/NMI` is quiet, no IRQ level would dispatch, no interrupt is latched, and no boundary tick sits inside the first parked iteration. Transient refusals decline the whole declaration (the next clean back-edge re-declares); only the page-cross case stores a permanently unarmed declaration. Every wake drops the declaration: each wait walks declare → skip → wake → re-declare with a fresh anchor.
- **Control seam (ticket #168, `NesMachine::set_spin_skip_enabled`)**: a default-off, test-only toggle on the machine. Detection and declaration run regardless of the switch; only span consumption is gated — so the differential sweep proves the declaration itself is observationally invisible. The freeze-era `set_spin_declaration_disabled_for_test` hook stays gone.
- **Testing (tickets #168/#170/#171, `nes_core/src/spin_skip_test.rs`)**: a differential sweep over every achievable start dot from scanline 240 dot 0 through scanline 242 dot 0 plus one at the frame wrap (229 targets; a synthetic iNES image built in code, first poll placed on a requested absolute dot via an exact-cycle delay tail) runs each machine skip-off and skip-on in the same build and requires identical CPU state, cycle count, and NMI dispatch dots at every frame boundary. The frame-hash harness compares against the pre-#132 baselines (`44addbd`) for SMB 600f, Jackal 1500f, vbl_basics, `nmi_sync`, and `vbl_wait`; `just passed` stays green. The perf claim itself is measured separately (#174, median wall time over interleaved runs, >2% win required).

## Consequences

- Frame correctness is the acceptance bar and the differential sweep is the primary guard: the freeze-era harness showed `nmi_sync`/`vbl_wait` can MATCH on a broken build, so the per-start-dot sweep — not the frame hashes — is what catches this bug class first.
- Because replays drive the published read path on exact grid dots, a future change to `$2002` read semantics, the latch refresh, or the interrupt poll automatically applies to the skip; only the grid arithmetic (21-dot period, anchor, poll offset) would need review.
- The interrupt machinery keeps its published-seam discipline: edge decisions come from real detectors on real line levels at real dots. Moving detection back into the skip path would recommit ADR-0019's mistake.
- The keep-first anchor rule means a declared loop's grid is decided once, at its first back-edge; anything that shifts that assumption (page-crossing branches, DMA-shaped stalls) must refuse or end the span rather than re-anchor.
- Device-register and `$2007` polls stay out of scope; broadening the shape family requires a new ADR, since each read's device effects must first be proven replayable through the published path.
- The decay-constant conflict (repo ~0.6 s vs nesdev 3–30 ms) is deliberately not resolved here; the contract holds for whatever #166 settles because only exact decay-clock advance is required.
